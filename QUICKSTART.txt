AI Digital COO Backend - Quick Start
=====================================

PREREQUISITES:
□ Node.js 20+
□ PostgreSQL 14+
□ Redis 7+

SETUP (5 minutes):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Install Dependencies
   npm install

2. Configure Environment
   Copy-Item .env.example .env
   # Edit .env - see ENV_VARS.txt below

3. Setup Database
   npx prisma generate
   npx prisma migrate dev --name init

4. Start Server
   npm run start:dev

5. Test Health Check
   curl http://localhost:3000/api/v1/health

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
